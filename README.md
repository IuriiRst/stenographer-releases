## First run — "Unknown publisher"

Stenographer isn't code-signed yet, so Windows SmartScreen may show a blue **"Windows protected your PC"** screen, and your browser may say the file **"isn't commonly downloaded."** This is normal for new independent apps — the file is safe (verify below). Choose **Keep** in the browser, then **More info → Run anyway** in SmartScreen.

## Verify your download

- **SHA-256:** `a8e59f76682c031244f750bfc7a8b83d147ff24e98c4b3bff5af540881f30a11`
- **VirusTotal:** [view scan](https://www.virustotal.com/gui/file/a8e59f76682c031244f750bfc7a8b83d147ff24e98c4b3bff5af540881f30a11)

Check it yourself in PowerShell: `Get-FileHash .\StenographerSetup.exe -Algorithm SHA256`

## Privacy

Dictation runs locally on your PC. Speech models download once, then work offline. Your voice and text are never sent anywhere for transcription.
